## Agni UI

An Angular component library built from scratch: standalone, signals only, with nothing underneath but the CDK. Every component is
checked in every palette, in light and dark, on a desktop and a phone.

- **See it:** [ui.agnisky.com](https://ui.agnisky.com), the showcase, also as a desktop and an Android app
  ([Downloads](https://ui.agnisky.com/downloads)).
- **What changed:** [the changelog](https://ui.agnisky.com/changelog).
